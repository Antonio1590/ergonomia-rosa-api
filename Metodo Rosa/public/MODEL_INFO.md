# Modelo YOLO — best.onnx

- **Tipo**: YOLOv8 detección de objetos (Ultralytics)
- **Clases**: chair, desk, document_holder, laptop, monitor, mouse, person, phone
- **Dataset**: Roboflow — workspace: antonios-workspace-b2le7
- **Entrenamiento**: Google Colab
- **Export**: ONNX
- **Tamaño**: ~11.7 MB
- **Runtime**: onnxruntime-web (WASM) — corre 100% en el navegador

Este modelo procesa imágenes localmente en el dispositivo del usuario.
Las fotografías NO se envían a ningún servidor externo.
